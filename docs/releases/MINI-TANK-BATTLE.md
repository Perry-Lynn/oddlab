# 迷你坦克战 · 首版

新增 /tanks/，首页「复古街机」区提供入口。原创 Canvas 像素图形与可选合成音效，无新增依赖。

- 三张地图：砖墙前哨、水道防线、钢铁十字。
- 每关分别有 12、16、20 辆敌方坦克，场上同时最多四辆；普通、快速和装甲三种类型，装甲需要两次命中。
- 三条命。清完本关敌人即可进入下一关，并保留得分和剩余生命；敌方子弹击中基地或生命耗尽则结束。
- 砖墙可摧毁，钢墙不可摧毁，子弹可以越过水域。自己的子弹不会损坏基地。
- 键盘：方向键或 WASD 移动，空格或 J 开火，P 或 Esc 暂停。手机支持方向区与开火键同时按住。
- 暂停时冻结规则；窗口失焦、页面隐藏和操作语言选择器时暂停。重开即时开始本关的新一局。
- 中英日西四语。切换语言保留战场状态；声音默认关闭。
- 只在浏览器保存本机最高分。战场、输入和路线不上传；Pages 继续禁用统计后台。

规则在 src/tanks-logic.mjs，文案在 src/tanks-copy.mjs，绘制和交互在 src/tanks-ui.mjs。后续新增地图修改地图表和对应文案即可；新增其他游戏沿用「复古街机」区。

验证：七组测试、Worker 构建和 Pages 构建校验；320/390/768/1280 宽度；四语开始按钮可达；模拟触屏双指移动和开火；暂停冻结、最高分恢复、本地存储禁用回退。窗口失焦事件已验证，自动化浏览器的新标签页不会真实改变页面可见性，因此后台行为还应在实际设备上试玩确认。
